# Summarize State Space Reconstruction

Provides a summary of the state space reconstruction results. This
function displays the dimensions, number of points, parameters, summary
statistics for each dimension, and the number of missing values.

## Usage

``` r
# S3 method for class 'pc_state'
summary(object, ...)
```

## Arguments

- object:

  A `pc_state` object.

- ...:

  Additional arguments passed to the `summary` function.

## Value

Invisibly returns the input object.
