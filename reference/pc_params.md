# Pattern Causality Parameter Optimization Results

Creates an object containing parameter optimization results for pattern
causality analysis

## Usage

``` r
pc_params(accuracy_summary, computation_time, parameters)
```

## Arguments

- accuracy_summary:

  Data frame containing accuracy results for different parameter
  combinations

- computation_time:

  Time taken for optimization

- parameters:

  List of optimization parameters

## Value

An object of class "pc_params"

## Details

Pattern Causality Parameter Optimization Results
