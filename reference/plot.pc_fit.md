# Plot Pattern Causality Results

Generates a combined plot of total causality and causality components
for a `pc_fit` object. This function combines the visualizations from
`plot_total` and `plot_components` into a single plot.

## Usage

``` r
# S3 method for class 'pc_fit'
plot(x, ...)
```

## Arguments

- x:

  A `pc_fit` object.

- ...:

  Additional arguments passed to the underlying plotting functions.

## Value

NULL invisibly.
