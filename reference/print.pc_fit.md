# Print Pattern Causality Results

Prints the pattern causality analysis results from a `pc_fit` object.
This function displays the total, positive, negative, and dark causality
strengths.

## Usage

``` r
# S3 method for class 'pc_fit'
print(x, ...)
```

## Arguments

- x:

  A `pc_fit` object.

- ...:

  Additional arguments passed to the `print` function.

## Value

Invisibly returns the input object.
