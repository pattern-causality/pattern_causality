# Plot Pattern Causality Time Series

Visualizes the positive, negative and dark causality components over
time

## Usage

``` r
# S3 method for class 'pc_full_details'
plot_causality(x, type, ...)
```

## Arguments

- x:

  A pc_full_details object

- type:

  The type of causality to plot ("total", "positive", "negative", or
  "dark")

- ...:

  Additional arguments passed to plotting functions

## Value

Invisibly returns the ggplot object
