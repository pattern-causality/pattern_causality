# Plot Total Causality

Visualizes the total causality strength as a barplot for a `pc_fit`
object. This function generates a barplot showing the total causality
strength and its complement.

## Usage

``` r
# S3 method for class 'pc_fit'
plot_total(x, ...)
```

## Arguments

- x:

  A `pc_fit` object.

- ...:

  Additional arguments passed to the underlying plotting functions.

## Value

NULL.
