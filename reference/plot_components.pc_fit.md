# Plot Causality Components

Visualizes the positive, negative, and dark causality components as a
barplot for a `pc_fit` object. This function generates a barplot showing
the strength of each causality component.

## Usage

``` r
# S3 method for class 'pc_fit'
plot_components(x, ...)
```

## Arguments

- x:

  A `pc_fit` object.

- ...:

  Additional arguments passed to the underlying plotting functions.

## Value

NULL.
