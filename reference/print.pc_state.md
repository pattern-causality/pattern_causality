# Print State Space Reconstruction

Prints the state space reconstruction results. This function displays
the parameters used for state space reconstruction and a preview of the
reconstructed points.

## Usage

``` r
# S3 method for class 'pc_state'
print(x, ...)
```

## Arguments

- x:

  A `pc_state` object.

- ...:

  Additional arguments passed to the `print` function.

## Value

Invisibly returns the input object.
