# Summarize Pattern Causality Results

Provides a summary of the pattern causality analysis results from a
`pc_fit` object. This function displays a table of causality strengths
for total, positive, negative, and dark components.

## Usage

``` r
# S3 method for class 'pc_fit'
summary(object, ...)
```

## Arguments

- object:

  A `pc_fit` object.

- ...:

  Additional arguments passed to the `summary` function.

## Value

Invisibly returns the input object.
